# Arbeitsanweisungen

- Deutschsprachige Texte verwenden echte Umlaute und ß.
- Dieses Repository beginnt als Planung. Produktcode nur im Umfang eines anschließenden konkreten Umsetzungsauftrags erstellen.
- Vor Umsetzung das Konzept, die jeweilige Story, Abhängigkeiten und das Entscheidungsregister lesen. Offene Fachwerte nicht erfinden.
- Ruby/Rails-Befehle nach Aufbau der Anwendung über mise mit der festgelegten Ruby-Version ausführen.
- Umfangreiche Produktänderungen auf eigenem Branch und mit passender Isolation durchführen.
- Jede funktionale Verwaltungsänderung aktualisiert Tests, Benutzerhandbuch und Changelog im selben Änderungssatz.
- Keine Secrets, realen Teilnehmerdaten, privaten Schlüssel oder Datenbanken einchecken.
